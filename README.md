# Promptoteca
PWA personal para guardar, organizar y copiar prompts. Preparada para GitHub Pages.

## Publicar
1. Crea un repositorio público llamado `promptoteca`.
2. Sube todo el contenido de esta carpeta a la raíz del repositorio.
3. En GitHub: Settings > Pages > Build and deployment > Deploy from a branch.
4. Selecciona `main` y `/ (root)`, y guarda.
5. Abre `https://TU-USUARIO.github.io/promptoteca/` en Safari del iPhone.
6. Compartir > Agregar a pantalla de inicio.

## Datos
Los prompts se guardan en localStorage del navegador. Usa Respaldo > Exportar JSON periódicamente y conserva el archivo en iCloud Drive/Files.
